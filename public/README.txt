ROXYLABS SVG PACKAGE

This package contains clean vector approximations based on the latest
AI-generated Roxylabs concept board. These are editable SVG files, but they
are not exact source vectors extracted from the generated image.

Included:
- roxylabs-mark-gradient.svg
- roxylabs-mark-black.svg
- roxylabs-mark-white.svg
- roxylabs-app-icon.svg
- roxylabs-favicon.svg
- roxylabs-horizontal-lockup-dark.svg
- roxylabs-horizontal-lockup-light.svg

Brand colors:
- Teal: #38D8C8
- Blue: #3478F6 / #245BFF
- Navy: #0F172A
- Off-white: #F8FAFC

The horizontal lockups use live text with Geist/Inter/Arial fallbacks.
For final production usage, converting the wordmark text to outlines in
Figma, Illustrator, or Inkscape is recommended.
